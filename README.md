# Alea Ann Forcado - Portfolio

Personal portfolio of Alea Ann Forcado, BSIT 3 - Section 3 at Western Institute of Technology. It shows my skills, my NC II certificate, school projects and project videos.

## Built with

- React
- CSS

## Run locally

```bash
npm install
npm start
```

Open http://localhost:3000 in your browser.

## Build

```bash
npm run build
```

The finished site is saved in the `build` folder.
